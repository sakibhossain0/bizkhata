BizKhata {version}, portable

To start BizKhata, open bizkhata.exe in this folder.

Keep everything in this folder together. bizkhata.exe can't run on its own, so
don't copy or move it out of the folder. For a desktop icon, right-click
bizkhata.exe and choose Send to > Desktop (create shortcut). On Windows 11,
Send to is under "Show more options".

To install BizKhata with Start menu and desktop icons instead, use
BizKhata-Setup-{version}.exe.

Your shop's data isn't kept in this folder (it's in %APPDATA%\BizKhata), so you
can replace the folder with a newer version without losing anything.

---

BizKhata চালু করতে এই ফোল্ডারের bizkhata.exe খুলুন।

ফোল্ডারের সব ফাইল একসাথে রাখুন। শুধু bizkhata.exe আলাদা করে কপি করলে অ্যাপ
চলবে না। ডেস্কটপে আইকন চাইলে bizkhata.exe-তে রাইট-ক্লিক করে
Send to > Desktop (create shortcut) বেছে নিন। Windows 11-এ Send to পাবেন
"Show more options"-এর ভেতরে।

Start menu আর ডেস্কটপ আইকনসহ ইনস্টল করতে BizKhata-Setup-{version}.exe চালান।

দোকানের তথ্য এই ফোল্ডারে থাকে না (থাকে %APPDATA%\BizKhata-তে), তাই নতুন
ভার্সনের ফোল্ডার দিয়ে এটি বদলে দিলেও কিছু হারাবে না।
